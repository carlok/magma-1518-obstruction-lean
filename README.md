# magma-1518-obstruction-lean

Lean 4-checked results about the Equational Theories Project (ETP) law 1518, `x = (y ◇ y) ◇ (x ◇ (y ◇ x))`:

1. **One-generated (1518 + 3862)-magmas are trivial or the Z/3 shift.** In any magma satisfying 1518 and 3862 (`x ◇ x = (x ◇ (x ◇ x)) ◇ x`), write `S x = x ◇ x`. For every `x` and all `u, v ∈ {x, S x, S (S x)}`, `u ◇ v = S v`, and `S (S (S x)) = x`. So the submagma generated by `x` is that set, with the shift's multiplication table, and it has one element or three. No finiteness is assumed. This is the conjecture stated by Terence Tao on the Lean Zulip on 2024-11-29 ([message 485148288](https://leanprover.zulipchat.com/#narrow/channel/458659-Equational/topic/Austin.20pairs/near/485148288)), with one target law instead of four and without finiteness. **Core Lean, no axioms** for the table and the closure (`lean/OneGenerated1518.lean`).
2. **Constant-coefficient magma cohomology cannot refute `1518 ⇒ 47, 614, 817, 3862` from any finite base.** Over the Z/3 shift every 1518-cocycle with values in a finite 1518-fibre is a coboundary (`H² = 0`), so every constant-coefficient 1518-extension of the shift is a direct product; combined with 1, an extension of a finite 1518-magma violates one of the four targets only if the base already does. The algebraic core (two certificate identities over `Z[b]/(b⁵ + b³ − b² − 1)`) is kernel-checked (`lean/L2Cert.lean`, `lean/H2Cert.lean`, axiom `propext` only); the reduction from finite fibres to that ring and the derivation of the cocycle equations are written proofs, not Lean.

What this is not: not a new implication or non-implication (all of them are settled by the ETP), not a statement about extensions whose coefficients vary with the base pair (the ETP's 15-element countermodel `Refutation939` is exactly such an extension of the shift by Z/5), and not a claim of novelty: the searchable venues were checked and nothing was found, which is different from a proof that nothing exists. Full statements, proofs, verification table, prior art and limits: `paper/l2_note.pdf`. A first-year-level tutorial of every prerequisite: `paper/prerequisites.pdf`.

lean +v4.33.1 lean/L2Cert.lean                  # ~9 s

## How result 1 was found

Vampire 5.1.0 proved the nine product identities from the two laws in milliseconds (`atp/eq_*.proof`, 9 to 32 lines, superposition and demodulation only). The Lean file is a hand transcription of those proofs, three to seven rewrite steps each. Hypothesis minimisation (`atp/min_*.p`): 3862 alone suffices; 47, 614 or 817 alone suffice only with left injectivity, which holds in finite 1518-magmas; without any target the closure is not provable and `Refutation939` is a one-generated counterexample.
